Branding Guidelines

Color Usage

  • Primary (#2E8B57) - Main actions, headers, highlights
  • Primary Dark (#236B43) - Hover states, darker backgrounds
  • Primary Light (#3CB371) - Active states, secondary highlights
  • Accent (#90EE90) - Borders, active indicators
  • Success (#27AE60) - Positive feedback, completed actions

Typography Rules

  • Use Inter font family for all UI text and documentation
  • Use Courier New/Monospace for code snippets and terminal output
  • Maintain at least 1.5 line-height for body text
  • Headers should use font-weight: 700 (bold)
  • Primary text color is #f0f0f0, secondary is #cccccc

Component Standards

  • All components use 4px border-radius for subtle rounding
  • Hover states should change background to primary color
  • Active states use accent color border (left or bottom)
  • Disabled states use opacity 0.5 and desaturated colors
  • All transitions use 0.2-0.3s duration with ease
